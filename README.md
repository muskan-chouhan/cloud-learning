# 📚 Cloud & DevOps Learning

A structured hands-on learning repository containing practice labs, command cheatsheets, architecture notes, and real-world configurations for **AWS, Linux, Git, and DevOps tools**.

---

## 🗂️ Repository Structure

* **`01-git-github-practice/`**  
  Git version control commands, branching strategies, workflows, and practice scenarios.

* **`02-linux-practice/`**  
  Linux system administration, user management, file permissions, networking commands, and shell scripting.

* **`03-aws-practice/`**  
  Core AWS services practice including EC2, S3, IAM, VPC, CloudWatch, and infrastructure configurations.

* **`.github/workflows/`**  
  GitHub Actions CI/CD workflows and automated build/deploy experiments.

---

## 🛠️ Key Topics Covered

- **Linux Administration:** Command-line basics, process management, networking, file systems, permissions,package management.
- **AWS Infrastructure:** Compute (EC2), Storage (S3), Database (RDS), Networking (VPC), Monitoring (CloudWatch),Load balancer(ALB).
- **Version Control & CI/CD:** Git branching, merge strategies, GitHub Actions deployment automation.
- **Networking Basics:** Port configurations, Security Groups, SSH access, DNS, and reverse proxy concepts.
