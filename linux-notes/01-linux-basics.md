# Day 1 - Linux Basics

## What is an Operating System (OS)?

An Operating System manages the computer hardware and software resources.

Examples:
- Windows
- Linux
- macOS

---

## What is Linux?

Linux is an Operating System commonly used in servers, cloud computing, and development environments.

---

## Linux Distributions

Linux has different distributions (versions):

- Ubuntu
- Amazon Linux
- CentOS
- Red Hat Enterprise Linux (RHEL)

---

## Windows vs Linux

### Windows
- User friendly
- Popular for personal computers
- More GUI focused

### Linux
- Lightweight
- Secure
- Stable
- Powerful terminal support
- Widely used in servers

---

## Why Linux is used in Servers?

- Stable
- Secure
- Lightweight
- Free and open source
- Excellent terminal and automation support

---

## Key Learning

Linux is an Operating System family used heavily in cloud environments.

Ubuntu, Amazon Linux, CentOS, and Red Hat are Linux distributions.

Most cloud servers run Linux because it is stable, secure, and efficient.
