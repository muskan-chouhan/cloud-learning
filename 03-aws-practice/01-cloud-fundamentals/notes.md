# Cloud Fundamentals

## Cloud Computing

Cloud Computing means using servers, storage, databases and networking over the internet instead of buying and managing physical infrastructure.

### Benefits

- Pay as you go
- Scalability
- High Availability
- No hardware maintenance

---

## Data Center

A Data Center is a physical building that contains servers, storage devices and networking equipment.

Purpose:
- Run applications
- Store data
- Provide services to users

---

## Server

A Server is a computer that provides services to other computers.

Example:
- Web Server
- Database Server

---

## Virtual Machine (VM)

A Virtual Machine is a software-based computer running on a physical server.

Benefits:
- Better resource utilization
- Easy management
- Multiple VMs on one physical server

---

## Public Cloud

Cloud services available to anyone over the internet.

Examples:
- AWS
- Azure
- Google Cloud

Benefits:
- Cost effective
- Easy to scale
- No hardware management

---

## Private Cloud

Cloud infrastructure dedicated to a single organization.

Benefits:
- More control
- More customization
- Better compliance for sensitive data

---

## Hybrid Cloud

Combination of Public Cloud and Private Cloud.

Example:
- Sensitive data in Private Cloud
- Website in AWS Public Cloud

---

## AWS Global Infrastructure

AWS Global Infrastructure is the worldwide network of AWS Regions, Availability Zones and Data Centers.

Benefits:
- Fast performance
- High availability
- Disaster recovery

---

## Region

A Region is a geographical area where AWS provides services.

Examples:
- Mumbai
- Singapore
- Tokyo
- London

Purpose:
- Low latency
- Data compliance
- Better user experience

---

## Availability Zone (AZ)

An Availability Zone is an isolated location inside a Region.

Purpose:
- High Availability
- Fault Tolerance

Example:

Mumbai Region
├── AZ-1
├── AZ-2
└── AZ-3

If one AZ fails, applications can run in another AZ.

---

## Local Zone

A Local Zone is an extension of an AWS Region placed closer to users.

Purpose:
- Reduce latency
- Improve application performance

Example:
Users are far from a Region, so AWS creates a Local Zone closer to them.

---

## Wavelength Zone

A Wavelength Zone places AWS infrastructure inside a telecom provider's network.

Examples:
- Airtel
- Jio
- Verizon

Purpose:
- Ultra low latency
- Real-time applications
- 5G applications

Use Cases:
- Gaming
- AR/VR
- Live streaming
- Autonomous vehicles

---

## AWS Outposts

AWS Outposts is AWS infrastructure installed inside a customer's data center.

Purpose:
- Run AWS services on-premises
- Keep sensitive data locally
- Hybrid Cloud solution

Benefits:
- AWS experience in own data center
- Better compliance
- Low latency for local systems
